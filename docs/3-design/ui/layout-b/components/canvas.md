## Canvas Behind Panels

```
Panels are rendered on top of canvas.
Canvas receives events when:
- Clicking directly on canvas (not on panels)
- Clicking through transparent panel areas

Click priority:
1. Panel content (forms, buttons)
2. Panel resize handles
3. Panel title bar (drag)
4. Canvas content
```
