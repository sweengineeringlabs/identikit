## Actions

| Element | Action |
|---------|--------|
| Format cards | Select export type |
| Resolution options | Output dimensions |
| Quality slider | JPEG compression |
| Background options | Set background color |
| Include checkboxes | PDF content options |
| [Browse...] | Choose save location |
| [Export X] | Begin export |
| [Open File] | Open exported file |
| [Open Folder] | Show in file manager |

---

**Layout**: C (Bottom Dock)
**Trigger**: File > Export or Ctrl+Shift+E
**Component**: `modals/ExportModal.tsx`
