## Actions

| Element | Action |
|---------|--------|
| Drop zone | Receive dropped images |
| [Browse Files...] | Open file picker |
| Resize options | Set initial scaling |
| [Use This Image] | Confirm and add |
| [Replace Reference] | Swap reference images |
| [Try Another File] | Reset and try again |
| [Cancel] | Close without changes |

---

**Layout**: C (Bottom Dock)
**Trigger**: Compare mode > Upload reference or drag image
**Component**: `modals/ReferenceUploadModal.tsx`
