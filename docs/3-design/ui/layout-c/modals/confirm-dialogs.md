## Actions

| Dialog | Primary Action | Secondary Action |
|--------|----------------|------------------|
| Delete Layer | [Delete] - Remove layer | [Cancel] - Keep layer |
| Unsaved Changes | [Save] - Save and proceed | [Don't Save] - Proceed without saving |
| Replace Feature | [Replace] - Swap features | [Add Anyway] - Keep both |
| Reset All | [Reset All] - Reset properties | [Cancel] - Keep current |
| Clear Canvas | [Clear All] - Remove layers | [Cancel] - Keep layers |
| Exit Compare | [Exit Compare] - Leave mode | [Cancel] - Stay in compare |
