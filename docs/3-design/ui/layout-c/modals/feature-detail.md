## Actions

| Element | Action |
|---------|--------|
| Large preview | Visual reference |
| Color swatches | Quick color selection |
| Custom color picker | Precise color choice |
| Scale slider | Pre-set initial size |
| Position options | Initial placement |
| Similar features | Quick alternatives |
| [Add to Composite] | Add feature to canvas |
| [Cancel] | Close without adding |

**Layout**: C (Bottom Dock)
**Trigger**: Click info icon on feature or double-click feature
