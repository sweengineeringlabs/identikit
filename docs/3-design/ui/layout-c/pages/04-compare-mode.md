## Actions

| Element | Action |
|---------|--------|
| Mode buttons | Switch comparison mode |
| [👁 Toggle Ref] | Show/hide reference |
| R key | Quick toggle reference |
| Opacity slider | Adjust reference transparency |
| Split slider | Move divider position |
| [⇄ Swap] | Swap left/right positions |
| [Exit Cmp] | Exit compare mode |
| Upload area | Add reference image |
| Dock collapse | More canvas space |
