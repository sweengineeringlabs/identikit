| Element | Action |
|---------|--------|
| Category tab | Filter to category |
| Search input | Search across all features |
| Feature card | Click to add to canvas |
| Feature card hover | Show quick actions |
| [View All] | Open full-screen browser |
| ◄ / ► arrows | Horizontal scroll |
| [▼]/[▲] | Expand/collapse dock height |
