## Actions

| Element | Action |
|---------|--------|
| X/Y inputs | Direct position entry |
| Scale slider | Resize feature |
| Rotation input | Precise rotation |
| [↻][↺] buttons | 90° rotation |
| [↔ H][↕ V] | Flip horizontally/vertically |
| Opacity slider | Layer transparency |
| Color zone swatches | Change zone colors |
| [🔄 Reset All] | Reset to defaults |
| Canvas handles | Direct manipulation |
