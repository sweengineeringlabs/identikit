## Actions

| Element | Action |
|---------|--------|
| Format cards | Select export format |
| Quality dropdown | Set output quality |
| Resolution options | PNG pixel dimensions |
| Include checkboxes | Toggle content sections |
| [Browse] | Choose save location |
| [Export] | Execute export |
| [Print] | Send to printer |
| Page nav | Preview multiple pages |
| Zoom dropdown | Preview zoom level |

---

**Layout**: C (Bottom Dock)
**Component**: `modals/ExportModal.tsx`, `modals/PrintPreviewModal.tsx`
**Hotkey**: Ctrl+P (Print), Ctrl+Shift+E (Export)
