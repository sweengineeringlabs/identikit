## Actions

| State | Actions Available |
|-------|-------------------|
| No composite | New, Open, Recent files |
| Empty canvas | Click/drag features from dock |
| Empty search | Clear search, browse categories |
| Empty category | Switch to other category |
| No selection | Click layer or canvas object |
| No reference | Upload or drag reference image |

**Layout**: C (Bottom Dock)
**Key Difference**: Empty states in dock area guide user to add features
