## Actions

| Interaction | Action |
|-------------|--------|
| Click feature | Select feature |
| Ctrl+Click | Add to selection |
| Click empty area | Deselect all |
| Drag selection | Move feature(s) |
| Drag corner handle | Resize proportionally |
| Drag side handle | Resize single axis |
| Drag rotation handle | Rotate |
| Scroll wheel | Zoom in/out |
| Middle-click drag | Pan canvas |
| Space + drag | Pan canvas (alternative) |
| Drop from dock | Add new feature |
| Delete/Backspace | Remove selected |

---

**Layout**: C (Bottom Dock)
**Component**: `components/canvas/CompositeCanvas.tsx`
**Key Difference**: Canvas height adjusts based on dock expansion state
