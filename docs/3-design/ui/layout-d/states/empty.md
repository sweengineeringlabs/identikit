## Actions

| State | Actions Available |
|-------|-------------------|
| No composite | New, Open, Recent files |
| Empty canvas | Click features in browser |
| Empty search | Clear search, browse |
| Empty category | Switch category |
| No selection | Click layer/canvas object |
| No reference | Upload reference image |

**Key Difference**: Empty canvas guides user to left panel for features
