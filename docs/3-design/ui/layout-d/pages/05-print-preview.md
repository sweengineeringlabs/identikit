## Actions

| Element | Action |
|---------|--------|
| Format cards | Select PDF/PNG/JPEG |
| Paper size dropdown | Set document size |
| Orientation radio | Portrait/Landscape |
| Quality dropdown | Set output quality |
| Include checkboxes | Toggle content sections |
| Resolution options | PNG/JPEG dimensions |
| Background options | Set image background |
| [Browse...] | Choose save location |
| [Export] | Begin export |
| [Print] | Send to printer |
| [Open File] | Open exported file |
| [Open Folder] | Show in file manager |

---

**Layout**: D (Split View Focus)
**Component**: `modals/ExportModal.tsx`, `modals/PrintPreviewModal.tsx`
**Hotkey**: Ctrl+P (Print), Ctrl+Shift+E (Export)
