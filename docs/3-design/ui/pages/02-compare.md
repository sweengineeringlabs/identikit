## Compare View Modes

| Mode | Best For |
|------|----------|
| **Split** | Side-by-side comparison |
| **Overlay** | Aligning features to reference |
| **Slider** | Before/after reveal |
| **Onion Skin** | Tracing reference features |
| **Difference** | Highlighting mismatches |

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| 1 | Split view |
| 2 | Overlay view |
| 3 | Slider view |
| 4 | Onion Skin view |
| 5 | Difference view |
| Esc | Exit Compare mode |
| +/- | Adjust reference opacity |
| Space | Toggle sync zoom |
