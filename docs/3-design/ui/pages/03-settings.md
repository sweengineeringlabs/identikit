## Settings Sections

| Section | Contents |
|---------|----------|
| General | Language, auto-save, startup, performance |
| Appearance | Theme, colors, UI scale, layout |
| Canvas | Grid, snapping, default size, background |
| Compare | Default view, opacity, sync options |
| Export | Default format, quality, metadata |
| Shortcuts | Keyboard shortcut customization |
| Feature Library | Library path, custom features |
| Backup | Auto-backup, cloud sync |
| About | Version, license, credits |
