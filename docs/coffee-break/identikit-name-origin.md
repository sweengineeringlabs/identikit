# The Name "Identikit"

"Identikit" is a real industry term - it was a trademarked name from the 1950s for one of the first facial composite systems used by law enforcement.

The original system used transparent overlays of facial features that investigators would stack together based on witness descriptions.

Over time, the name became genericized, like "xerox" for photocopying or "kleenex" for tissues.

Today, "identikit" (lowercase) is often used generically to describe any facial composite system, regardless of manufacturer.
